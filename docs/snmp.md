# SNMP

La primera versión no ejecuta consultas SNMP y no presenta datos SNMP simulados como reales. La siguiente fase añadirá un módulo aislado para SNMPv3, secretos locales excluidos de Git, identificación `sysName`, interfaces IF-MIB y marcas de actualización. SNMPv1/v2c solo se considerará para laboratorios controlados; las comunidades jamás se registrarán ni devolverán por la API.
