# Roadmap

1. Retención configurable, agregados horarios y exportación de reportes.
2. ICMP opcional con privilegios explícitos y resultados separados de TCP.
3. Módulo SNMPv3 con secretos locales y métricas de interfaces.
4. Autenticación, roles y bitácora de operador.
5. Descubrimiento verificable de topología y Prometheus/Grafana opcionales.
